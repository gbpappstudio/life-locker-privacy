# Life Locker — Privacy Policy

Public host for the [Life Locker](https://github.com/gbpappstudio/life-locker-android) (private)
privacy policy, served via GitHub Pages so the Play Console listing and the in-app link have a
live URL.

**Live page:** https://gbpappstudio.github.io/life-locker-privacy/

Source of truth is `PRIVACY_POLICY.md` in the app repo; `index.html` here is the rendered copy.
Keep them in sync when the policy changes.
